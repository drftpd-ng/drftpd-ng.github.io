# Legacy Pages

**Warning:** the pages listed here were written for DrFTPD 2.0 and 3.x. They are kept untouched for history only. Commands, configuration files, paths, plugin names, the build system (Ant/SVN) and the Java versions they describe **do not apply to DrFTPD 4.x**. Use the current pages in the sidebar instead, starting with [Introduction](Introduction.md) and [Installation on Linux](Installation-Linux.md).
